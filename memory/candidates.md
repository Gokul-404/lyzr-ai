# GitAgent Interviewer — Candidate Memory Store

This file tracks all interviews conducted and their outcomes.

## Format

Each entry is a YAML record with candidate username, interview date, verdict, and score.

```yaml
- username: candidate_username
  interview_date: 2026-05-23
  challenge_template: challenge_junior | challenge_senior
  verdict: strong hire | hire | consider | no hire
  score: 85 (out of 100)
  pr_url: https://github.com/...
  time_taken_minutes: 45
  feedback_snippet: "..."
```
